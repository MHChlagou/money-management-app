# Monthly Money

A personal, offline-first money tracker. Enter your salary each month, configure your
recurring costs once (subscriptions, credits, bills), and see how much is left and where to
optimize. Installs as an app on Windows, iPhone and Android with no app store.

Data never leaves your device. Use **Settings → Export backup** to move it between devices.

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
npm run preview    # serve dist/ locally
```

## Put it online (needed to install on iPhone)

Installing a web app requires HTTPS, so host the `dist/` folder somewhere. Two free options:

**Option A: GitHub Pages (automatic)**
1. Push this folder to a GitHub repo (private is fine) on a branch named `main`.
2. Repo → Settings → Pages → Source: **GitHub Actions**.
3. The included workflow builds and deploys on every push. Your app is at
   `https://<user>.github.io/<repo>/`.

**Option B: Netlify Drop (drag and drop)**
1. `npm run build`
2. Open https://app.netlify.com/drop and drag the `dist/` folder onto it.

## Install

| Platform | Steps |
|---|---|
| Windows (Edge / Chrome) | Open the URL → click the install icon at the right end of the address bar (or menu → Apps → Install this site as an app). |
| Android (Chrome) | Open the URL → tap the "Install" banner, or ⋮ menu → Add to Home screen. |
| iPhone / iPad | Open the URL **in Safari** → Share button → Add to Home Screen → Add. |

After installing, the app works fully offline and updates itself when you redeploy.

## Features

- **Month**: salary (with a default so you don't retype it), extra income, what's left, recurring lines you can skip or adjust for that month, one-off expenses (tap to edit, undo on delete), a note per month, and "coming up in 7 days".
- **Calendar**: which day each payment leaves the account, how much is gone so far this month, and what's still to pay. Tap a day to add an expense.
- **Recurring**: subscriptions, credits and bills with a billing frequency (monthly, quarterly, yearly…), a start and end month, a payment day, and pause/resume. Shows the true monthly equivalent of yearly charges.
- **Insights**: optimization suggestions, per-category budgets, a category donut, income vs. expenses over six months, and a full-year overview.
- **Settings**: currency, savings goal, default salary, light/dark theme, category editor (icon, colour, budget), backup export/import, example data.

## How it works

- `src/lib/types.ts`: data model. Recurring items are templates with a start month and an
  optional end month (for credits). Each month can override or skip any line.
- `src/lib/calc.ts`: resolves which templates apply to a month and computes totals.
- `src/lib/insights.ts`: optimization rules. Add your own in `personalRules()`.
- `src/lib/store.ts`: state persisted to localStorage.
- `src/pages/*`: the four screens (Month, Recurring, Insights, Settings).

Icons are generated by `node scripts/make-icons.mjs` (no image tools needed).
